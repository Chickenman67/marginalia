# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four small UI fixes — filter pill+panel in a top bar per view, compact single-line todo cards, stars always at full opacity, drag-reorder removed.

**Architecture:** Give each view two children: a `.view-bar` (filter pill + panel) and a `.view-cards` (where cards are rendered). `renderAll()` writes only to the cards container, never to the bar. `cardHTML` switches between two layouts based on `i.kind`: todo gets a one-line flex row, event keeps the existing two-line layout. Star widget is inlined into the todo card HTML. Drag handle and listeners are removed.

**Tech Stack:** TypeScript, vanilla DOM, Vite, Vitest. No new dependencies.

## Global Constraints

- Theme is unchanged: same `--paper`/`--panel`/`--ink`/`--line`/`--event`/`--todo` tokens. No new colors.
- No new dependencies.
- TypeScript strict mode must pass `tsc --noEmit` after every task.
- All existing tests must continue to pass. Three new tests added for the compact todo card.
- The `reorder` function and `order` field stay in place; only the UI affordance is removed.
- The star widget's `data-pos` attribute and click-zone logic from the previous branch are preserved.

- [ ] **Step 3: Refactor `cardHTML` in `src/ui/views.ts`**

Open `src/ui/views.ts`. The current `cardHTML` (around lines 215-254) renders one markup for both kinds. Replace it with a function that branches on `i.kind`:

```ts
export function cardHTML(i: Item, opts: { selectable?: boolean; selected?: boolean; showPin?: boolean } = {}): string {
  if (i.kind === "todo") return todoCardHTML(i, opts);
  return eventCardHTML(i, opts);
}

function todoCardHTML(i: Item, opts: { selectable?: boolean; selected?: boolean }): string {
  const isPast = false; // todos don't have a past state
  const accent = colorFor(i.datetime || i.reminder);
  const accentAttr = accent ? ` data-accent="${accent}"` : "";
  const sel = opts.selectable
    ? `<input type="checkbox" class="sel" ${opts.selected ? "checked" : ""} aria-label="Select ${esc(i.title)}" />`
    : "";
  return `<div class="card todo ${i.status === "done" ? "done" : ""} ${isPast ? "past" : ""} ${opts.selected ? "selected" : ""}" data-id="${i.id}"${accentAttr}>
    ${sel}
    <input type="checkbox" class="check" ${i.status === "done" ? "checked" : ""} aria-label="Complete ${esc(i.title)}" />
    <div class="body">
      <div class="title">${esc(i.title)}</div>
      <span class="badge todo">todo</span>
      ${starHTML(i.rating, i.id)}
    </div>
    <button class="del" title="Delete" aria-label="Delete ${esc(i.title)}">🗑</button>
  </div>`;
}

function eventCardHTML(i: Item, opts: { selectable?: boolean; selected?: boolean; showPin?: boolean }): string {
  const isPast = i.kind === "event" && !!i.datetime && new Date(i.datetime) < new Date() && i.status !== "done";
  const time = i.kind === "event" && i.datetime ? (i.all_day ? "" : clock(i.datetime)) : "";
  const remind = i.reminder ? `<span class="remind">🔔 ${clock(i.reminder)}</span>` : "";
  const accent = colorFor(i.datetime || i.reminder);
  const accentAttr = accent ? ` data-accent="${accent}"` : "";
  const sel = opts.selectable
    ? `<input type="checkbox" class="sel" ${opts.selected ? "checked" : ""} aria-label="Select ${esc(i.title)}" />`
    : "";
  const pin = opts.showPin === false
    ? ""
    : `<button type="button" class="pin-btn ${i.pinned ? "on" : ""}" title="${i.pinned ? "Unpin" : "Pin"}">${i.pinned ? "📌" : "📍"}</button>`;
  return `<div class="card ${i.status === "done" ? "done" : ""} ${isPast ? "past" : ""} ${opts.selected ? "selected" : ""}" data-id="${i.id}"${accentAttr}>
    ${sel}
    <input type="checkbox" class="check" ${i.status === "done" ? "checked" : ""} aria-label="Complete ${esc(i.title)}" />
    <div class="body">
      <div class="title">${esc(i.title)}</div>
      <div class="meta">
        <span class="badge ${i.kind}">${i.kind}</span>
        ${i.all_day ? `<span class="badge allday">all day</span>` : ""}
        ${time ? `<span>${time}</span>` : ""}
        ${remind}
      </div>
    </div>
    ${pin}
    <button class="del" title="Delete" aria-label="Delete ${esc(i.title)}">🗑</button>
  </div>`;
}
```

(Notes: `starHTML` and `esc` are already exported from this file. `colorFor` and `clock` are already imported at the top. The old `cardHTML` body becomes `eventCardHTML` verbatim except for the dropped `${handle}` line — events never had the drag handle anyway, so this preserves the old event rendering exactly.)
